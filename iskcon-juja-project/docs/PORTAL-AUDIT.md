# Member portal and admin portal audit (M1, 18 Nov 2026)

## Member portal (what a member sees)
Pages: Home (dashboard), My Courses, Calendar, Messages, Profile, plus the course catalog.

| Finding | Proposal |
|---|---|
| Top of every page is tall (logo bar, menu bar, welcome banner, lunar-day strip) before any content | Keep the menu bar; fold the welcome banner into the dashboard (show once, then never again) and put the lunar-day strip inside the dashboard and Calendar only |
| Dashboard is almost empty: Verse of the day and a big "Explore our courses" box | Make it the one place a member checks daily: Verse of the day, "What Srila Prabhupada said today", today's lunar day, next programs (Tuesday, Friday, Sunday and special events), message-board unread count, my courses with progress |
| "Explore Our Courses" box, "My Courses" and the catalog repeat each other | One "Courses" menu item: my courses on top, the catalog below |
| My Courses says "course progress tracking are coming soon" (stale) | Remove the sentence; show progress when a course is joined |
| Courses catalog page shows the public-site menu even for a signed-in member | Show the member menu when signed in |
| Profile is one very long page (name and phone, 10 questions, plan ahead, my dates, password, delete) | Split into 3 collapsed sections: "My details", "My dates and reminders", "Account (password, delete)". The 10 questions go in a collapsed "About me (optional)" |
| Message board asks to choose a name before showing anything | Keep, but only the first time |

## Admin portal (tabs)
Main: Overview, People, Message Board, Testimonials, Events and Programs, Quotes, Sign-ups, Courses, Settings. Under "More tools": Articles, Merchandise, Business Card.

| Finding | Proposal |
|---|---|
| Three lines still say "Events page" (it is now the home page Events section) | Fix the wording |
| Quotes: only a paste box; list is long | Add "Upload a text file" (owner request), a theme filter (Sun to Sat), theme shown on each row, and a count of live and draft quotes |
| Overview: 4 counters and 4 quick actions | Add: quote of today, next 3 events, sign-ups this week |
| Settings: "Payments (on hold)" drawer is not in use | Hide until payments are started |
| Articles: the home page Insights section is switched off in the settings, so the tab is unused | Hide the tab while the section is off, keep the data |
| Message Board and Testimonials are separate small tabs | Merge into one "Community" tab with two sections |
| Business Card | Keep under More tools |
| Events: no automatic clean-up; no yearly repeat | Owner's calendar item: remove events after they pass, mark yearly events, remind admin a week before |

## Order of work (after the owner approves)
1. Admin: stale wording, quote file upload, theme filter, hide Payments and Articles, merge Community, richer Overview.
2. Member: dashboard, merged Courses, profile sections, member menu on the catalog.
